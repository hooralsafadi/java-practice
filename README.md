
# Java Practice

A collection of Java programs and exercises created as I develop my programming skills.

## About

I am learning Java independently through beginner-friendly coding exercises and practical projects. This repository documents my progress as I build my understanding of programming fundamentals, practise problem-solving, and learn to write and debug code.

These projects are learning exercises rather than production-ready applications. I use them to apply new concepts and gradually take on more challenging problems.

## Learning Goals

- Develop a strong understanding of Java fundamentals
- Practise writing, testing, and debugging code
- Strengthen logical thinking and problem-solving skills
- Apply programming concepts to practical problems
- Explore applications of programming in cybersecurity and artificial intelligence

## Programs

1. **HelloWorld.java** - Prints messages to the console.
2. **PersonalIntroduction.java** - Uses variables to store and display personal information.
3. **VariableUpdate.java** - Demonstrates how to update a variable's value.
4. **BasicCalculator.java** - Uses arithmetic operators to perform basic calculations.
5. **AgeChecker.java** - Uses `if` and `else` statements to make decisions based on a condition.
6. **GradeChecker.java** - Uses `if`, `else if`, and `else` to classify a mark.
7. **MultiplicationTable.java** - Uses a `for` loop to print a multiplication table.
8. **NumberGuessingGame.java** - Uses user input, a `while` loop, and conditional statements to create a number guessing game.
9. **StudentGradeCalculator.java** - Accepts three marks, calculates their average, and assigns a grade.
10. **PasswordStrengthChecker.java** - Checks password length and character types, calculates a basic score, and provides feedback on missing requirements.
